# Greghtech

Persistent companion data for a personal GregTech: New Horizons playthrough.

The project-local skill is stored in `.agents/skills/gtnh-companion/`. Its
`references/` directory contains the recorded player state, quest progress,
version-specific recipe notes, and optimization notes.

After cloning this repository on another computer, open the cloned folder as a
local project in Codex. The `gtnh-companion` skill and the saved playthrough
state will then be available from that project.
